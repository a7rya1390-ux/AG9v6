</p>About AG9

AG9 is a personal portfolio website designed to present professional identity, projects, skills, and digital activities through a modern and organized experience.

Version 6 continues the development of the previous AG9 versions, focusing on improved branding, accessibility, search engine optimization, and a bilingual experience.

Features

- Modern and responsive website design
- Separate English and Persian versions
- Personal profile and professional introduction
- Museum section for showcasing work and achievements
- Support section
- Social media integration
- Updated personal branding and profile image
- SEO improvements and metadata
- Open Graph integration
- Structured data (Schema.org)
- Sitemap and robots.txt
- AI discoverability support through llms.txt

Website Sections

Section| Description
Home| Personal introduction and digital identity
Museum| Projects, achievements, and portfolio content

Then open:

http://127.0.0.1:8000
